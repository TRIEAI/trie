# Security reports / 安全反馈

Please report suspected vulnerabilities privately to contact@trie.ai. Include the affected version and reproduction steps with non-sensitive sample data. Do not post credentials, recordings or private user content in public issues.

发现安全问题请通过 contact@trie.ai 私下联系，提供受影响版本和不含敏感数据的复现步骤。请勿在公开 issue 中发布密钥、录音或用户私人内容。
